报告 .env 文件中的 LangSmith 配置错误，这些错误会静默禁用跟踪或导致运行时错误：已弃用的 LANGCHAIN_* 密钥（规范名称为 LANGSMITH_*）、设置为不同值的旧版密钥和现代密钥、非小写字符串 true 的跟踪标志、错误的区域端点主机（例如，eu.smith.langchain.com 而非 eu.api.smith.langchain.com）、缺失的 API 密钥，以及从未启用的跟踪。

有问题的配置示例：


LANGCHAIN_TRACING_V2=True
LANGCHAIN_API_KEY=lsv2_sk_...
LANGCHAIN_ENDPOINT=https://eu.smith.langchain.com

快速修复会按规范形式重命名密钥，将跟踪值规范化，纠正端点主机，并插入缺失的密钥。

该检查仅在依赖于 langsmith、langchain 或 langgraph 的项目中运行。
