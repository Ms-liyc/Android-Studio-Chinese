报告在同一文件中的 langchain、langsmith 或 langgraph import 之后运行的 load_dotenv() 调用。 这些 SDK 在导入时会读取并缓存跟踪配置，因此随后的 load_dotenv() 会被忽略而不会产生任何错误，并且跟踪功能会保持禁用状态。

示例：


from langchain_openai import ChatOpenAI
from dotenv import load_dotenv

load_dotenv()

该快速修复会将 load_dotenv() 及其 import 移至 LangChain/LangSmith import 之上。
